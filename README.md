# Weather forecast project

This repository contains my personal project predicting today's weather using LightGBM model. Files included (in alphabetical order):

### backfill_column.py 
Allows to download historical data for new column if decided to add. To do this:
1. add new column's name in _config.py_ in _DAILIES_
2. execute updating script in terminal:
`python backfill_column.py --col <column_name>`

### config.py
Contains constant variables for project: cities names and coordinates, sorted cities names, archive api address, database name and weather parameters.

### fetch_daily.py
Checks the last recorded date for each city and fetches all missing historical data up to yesterday.

### main.py
Creates historical weather database if one doesn't already exist. Executes functions from other programs ( init_db(), run_fetch(), run_stats(), run_training(), run_prediction() ).

### model_features.joblib
Contains in order features used by prediction model to ensure correct prediction making.

### predict_today.py
Creates prediction for today's weather's max temperature.

### requirements.txt
Contains libraries to download by github workflow.

### weather_forecast.db
Historic database file ( starting 01-01-2009 ).

### weather_lgbm_model.joblib
contains the trained LightGBM model.

### weather_stats.py
Calculates global and per city MAE and RMSE and generates daily plot comparing predicted temperature and real temperature per city.

### weather_train_model.py
Trains the LightGBM model if the model file is missing or on the 1st and 15th day of each month.

### /.github/workflows/daily_pipeline.yml
Workflow file for github actions.

## Additions
Other, nonessential files

### /plots
.png plots generated by `weather_stats.py`. The images are in format `YYYY-MM-DD_weather_plot.png`.

### /experiments/model_comparison.py
Comparison of different models ( Same temperature as yesterday, Ridge, Random Forest, LightGBM, MLP ). It was made before the start of the actual project to evaluate which model performs the best in predicting weather. 

### /experiments/prediction_compare.xlsx
Addition to previous file which compares model accuracy depending on the starting date of training data. It was essential in choosing the model.
